# About me
- I'm a complete beginner. I have never coded before.
- I'm a designer building a portfolio game called "Patang", a rooftop kite-fighting game.

# How to work with me
- Before each change, explain what you're about to do in simple, non-technical language.
- Build in small stages. After each stage, stop and tell me exactly how to open and test it,
  and what I should see. Wait for my feedback before moving on.
- When something breaks, explain why in plain English, then fix it.
- Never add features I didn't ask for. Suggest them instead.
- After each working stage, remind me to save a checkpoint.

# Technical choices
- Keep the game in a single index.html file for now.
- Load libraries from a CDN. Nothing to install.
- Keep all tunable numbers (wind, gravity, tension, kite weight, etc.) together in one
  clearly labeled settings section near the top of the file, with a plain-English comment
  next to each one.
- It must work with mouse AND touch.
