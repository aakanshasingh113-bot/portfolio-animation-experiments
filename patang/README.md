# Patang

A rooftop kite-fighting game inspired by Uttarayan / Makar Sankranti.
Everything lives in one file: `index.html`.

## How to open it

- **On your computer:** download `index.html` and double-click it (you need to be online,
  because the game toolkit loads from the internet).
- **On Vercel:** open the latest preview link and add `/patang/` to the end of it.

## Controls

| Action | Mouse / touch | Keyboard |
| --- | --- | --- |
| Pull | Press and hold | Space |
| Release | Let go | Let go of Space |
| Steer | While holding, slide left or right | Left / Right arrows |
| Restart | Tap after a cut or snap | R |
| Pause | | P |
| Slow motion | Slow-mo button | S |
| Tuning panel | ⚙ button | T |
| Sound on/off | 🔊 button | M |
