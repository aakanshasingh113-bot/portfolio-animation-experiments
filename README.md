# portfolio-animation-experiments

## The Bunny Who Packed Too Much — flipbook

`bunny-flipbook/` turns the illustrated storybook into an interactive book with turning pages.

- Two-page spreads on wide screens (the spread illustrations line up across the gutter), one page at a time on phones
- Tap a page, swipe, drag the corner, or use the arrow keys to turn
- Soft paper-rustle sound (toggleable)
- No build step or dependencies: open `bunny-flipbook/index.html` through any static server, e.g. `python3 -m http.server` inside the folder
