# What's in my bag — Aakansha Singh's portfolio

Next.js (App Router) + TypeScript + Tailwind, `matter-js` for the spill, `framer-motion` for the tags.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
```

- **Everything in the bag** lives in `data/items.ts`: labels, tags, links, statuses, sizes and resting positions.
- **Photos:** drop a transparent PNG at the item's `image` path (e.g. `public/items/watch.png`) and rebuild. It replaces the illustrated placeholder automatically.
- **Résumé:** replace `public/resume.pdf`.

Status: Phase 1 (homepage). Case studies, About, 404 and the password gate come next.
